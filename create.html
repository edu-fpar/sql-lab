    Exercice complet (.zip)

    La base, son contexte et les questions dans un seul fichier. L'étudiant l'importe avec « Importer un fichier » ; un autre enseignant peut le charger ici.

    Paquet SCORM (Moodle…)

    L'application complète, verrouillée sur cet exercice (base + questions cochées ci-contre), à déposer dans Moodle comme « Paquetage SCORM ». Score transmis : % de questions réussies ; l'étudiant reprend où il en était.

    Fichier

    À déposer sur Moodle, à envoyer par mail… L'étudiant l'importe avec « Importer un fichier » dans SQL Lab.

    Lien sans serveur

    Les questions sont contenues dans le lien lui-même (compressées). Rien n'est hébergé ni envoyé à un serveur.

    Tester

    Lien vers un fichier hébergé

    Si vous déposez le JSON en ligne (GitHub, Gist « raw », votre site…) : les étudiants verront toujours la dernière version.

    Le site doit autoriser la lecture depuis une autre page (en-tête CORS) : c'est le cas de GitHub et des Gists, rarement de Moodle.

    Solution

    Dessinez le schéma attendu à partir du départ : nouvelles tables, clés primaires, références, attributs à retirer.

    Corrigé

    Dessinez le schéma événements-résultats : acteurs, événements, opérations et leurs règles d'émission, synchronisations.
