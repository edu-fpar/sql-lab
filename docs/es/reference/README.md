# Referencia

Formatos de archivo y herramientas, para los profesores que escriben sus propias preguntas y
para los desarrolladores.

| Página | Contenido |
|---|---|
| [Formatos de archivo](es/reference/formats) | preguntas de SQL, de esquema y de procesos, paquetes de preguntas, zip de ejercicio, campo `cinema` |
| [Añadir un ejercicio](es/reference/exercise) | base de datos, preguntas, entrada en el catálogo, pruebas |
| [Paquete SCORM](es/reference/scorm) | puntuación, estado, reanudación, creación por línea de comandos |
| [Estructura y herramientas](es/reference/tools) | árbol de archivos, pruebas, capturas, publicación |

El formato de las preguntas también está descrito para las IA en el
[skill sql-lab-questions](https://github.com/edu-fpar/sql-lab/blob/main/skill/sql-lab-questions/SKILL.md)
(en francés; las claves JSON son las mismas en todos los idiomas).
