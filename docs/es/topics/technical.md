# Visión técnica

- **Componentes**: HTML y JavaScript sin paso de compilación, sql.js 1.10 (SQLite en
  WebAssembly), CodeMirror 5, fflate. Las bibliotecas están incluidas en `lib/`.
- **Formatos JSON**: preguntas (`sql-lab-questions/1`) y ejercicios (`sql-lab-exercice/1`),
  descritos en el [README](es/reference/) y en el [skill](https://github.com/edu-fpar/sql-lab/blob/main/skill/sql-lab-questions/SKILL.md).
- **Pruebas**: `tools/test_exercice.js` (soluciones, alternativas, trampas, esquemas, procesos)
  y `tools/test_pack.js`.
- **Capturas de pantalla**: `tools/captures.js`.
