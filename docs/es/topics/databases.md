# Bases de datos propias

- **Formatos aceptados**:
  - un archivo `.sqlite`, `.db` o `.sql` solo (ejercicio sin preguntas);
  - o un zip que contenga `exercice.json` con `db.sqlite` o `db.sql`.
- **Comprobaciones en la importación**:
  - el archivo debe ser válido, con al menos una tabla;
  - se vigila el tamaño;
  - se señalan las fechas con formato incorrecto (se exige AAAA-MM-DD);
  - se señalan las claves foráneas ausentes, ya que el diagrama no tendría flechas.
- **Dónde se guarda el ejercicio**: se queda en el navegador del estudiante (IndexedDB) y se
  puede eliminar.
