# Compartir y plataformas

| Opción | Para qué | Nota |
|---|---|---|
| Archivo JSON | unas cuantas preguntas sobre una base de datos existente | «Importar un archivo» en el lado del estudiante |
| Enlace sin servidor | compartir rápidamente (mensajería, entorno virtual) | preguntas comprimidas después del `#` |
| Enlace a un archivo alojado | actualizar sin enviar un nuevo enlace | el sitio debe permitir CORS |
| Ejercicio completo (.zip) | tu propia base de datos | archivo o enlace `?exercice=` |
| Paquete SCORM | notas y seguimiento en el LMS | un paquete por ejercicio |
