# Référence

Formats de fichiers et outils, pour les enseignants qui écrivent leurs propres questions et pour
les développeurs.

| Page | Contenu |
|---|---|
| [Question SQL](reference/questions) | champs d'une question (`enonce`, `correction`, `variantes`, `ordered`, `verif`…) |
| [Question de schéma](reference/schema) | `depart`, `solution`, noms acceptés, variantes partielles |
| [Question de processus](reference/processus) | couloirs, synchronisations attendues, auto-évaluation |
| [Correction pas à pas](reference/pas-a-pas) | génération automatique, champ `cinema` |
| [Packs de questions](reference/packs) | espace enseignant, partage par fichier ou par lien |
| [Exercice et base](reference/exercice) | zip `sql-lab-exercice/1`, ajouter un exercice au catalogue |
| [Paquet SCORM](reference/scorm) | score, statut, reprise, construction en ligne de commande |
| [Structure et outils](reference/outils) | arborescence, tests, captures d'écran, publication |

Le format des questions est aussi décrit pour les IA dans la
[skill sql-lab-questions](https://github.com/edu-fpar/sql-lab/blob/main/skill/sql-lab-questions/SKILL.md).
