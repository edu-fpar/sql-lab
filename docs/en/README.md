# SQL Lab documentation

**[Open the app (English demo)](https://edu-fpar.github.io/sql-lab/?lang=en#demo-en/intro)** ·
[Teacher space](https://edu-fpar.github.io/sql-lab/create.html?lang=en) ·
[Source code](https://github.com/edu-fpar/sql-lab)

SQL Lab is a web app for practising SQL, built for business students. Queries run **in the
browser**: nothing to install, no account, no data sent anywhere. It offers:

- an English demo exercise, and 18 exercises from the French DCG accounting exams (2008–2026)
  with about 450 SQL questions;
- schema-design and process questions;
- animated step-by-step solutions;
- a teacher space to create questions with AI, use your own database and export to SCORM.
