      Complétion : tapez le début d'un nom de table ou de colonne, ou Ctrl+Espace ; après CLIENT. (ou un alias C.) les colonnes de la table sont proposées.

      Aide-mémoire SQL

      Consultation

      SELECT colonne1, colonne2
FROM TABLE1, TABLE2
WHERE TABLE1.cle = TABLE2.cle
  AND condition
GROUP BY colonne1
HAVING COUNT(*) > 3
ORDER BY colonne1 DESC;

      Jointure avec JOIN

      SELECT colonne1, colonne2
FROM TABLE1
INNER JOIN TABLE2
  ON TABLE1.cle = TABLE2.cle
WHERE condition;

      Sous-requête

      WHERE id NOT IN (SELECT id
                 FROM TABLE2)

      Mises à jour

      INSERT INTO TABLE VALUES (v1, v2);
UPDATE TABLE SET col = valeur
  WHERE condition;
DELETE FROM TABLE WHERE condition;

      Dates

      • YEAR(d), MONTH(d), DAY(d)
      • '15/06/2024' ou #15/06/2024# sont acceptés
      • BETWEEN '01/01/2023' AND '31/12/2023'
      • NOW() / CURDATE() : date du jour simulée
      • DATEDIFF(fin, début) : écart en jours

      Pièges fréquents

      • IS NULL et non = NULL
      • décimales avec un point : 4.34
      • condition sur COUNT/SUM → HAVING
